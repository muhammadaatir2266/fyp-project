===========================================
FYP-ADMIN APPLICATION PLAN
Central Management Panel for Healthcare Platform
===========================================

PROJECT OVERVIEW
===========================================
The fyp-admin app is the central control panel for the entire healthcare platform.
It manages doctors, appointments, API tokens, and the calling agent integration system.

ARCHITECTURE DECISION
===========================================
✓ Calling Agent API endpoints moved from fyp-doctor to fyp-admin
✓ API token authentication required for external access
✓ Admin can generate/revoke API tokens
✓ All API calls are logged for monitoring
✓ Centralized management of the entire system

TECH STACK
===========================================
Frontend:
- Next.js 15+ with TypeScript
- Tailwind CSS v4
- Shadcn UI components
- Framer Motion for animations

Backend:
- Express.js with TypeScript
- PostgreSQL with Prisma ORM
- JWT for admin authentication
- API token system for external access

API TOKEN AUTHENTICATION FLOW
===========================================

1. Admin generates API token in dashboard
2. Token is stored in database with metadata
3. External system (calling agent) includes token in header:
   Authorization: Bearer <token>
4. Middleware validates token before allowing access
5. Each API call is logged with token ID
6. Admin can view usage and revoke if needed
