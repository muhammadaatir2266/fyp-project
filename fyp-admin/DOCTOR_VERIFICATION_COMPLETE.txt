STATUS: ✅ FULLY IMPLEMENTED AND TESTED

OVERVIEW:
---------
The doctor verification system allows administrators to review, approve, or reject doctor applications with document verification.

BACKEND IMPLEMENTATION:
-----------------------
✅ Database Schema (Prisma)
   - verificationStatus enum (PENDING, APPROVED, REJECTED)
   - licenseNumber field
   - clinicLocation field
   - verificationDocument field (file path)
   - verificationNotes field (rejection reasons)
   - verifiedAt timestamp
   - verifiedBy admin ID reference
   - isActive default set to false

✅ API Endpoints (fyp-admin/backend)
   - GET /admin/doctors?verificationStatus=PENDING|APPROVED|REJECTED
   - POST /admin/doctors/:id/approve
   - POST /admin/doctors/:id/reject (requires notes)
   - GET /admin/doctors/:id/verification-document
   - Dashboard stats include pendingDoctors count

✅ Security Features
   - Admin authentication required for all endpoints
   - Path validation to prevent directory traversal attacks
   - Document access restricted to authenticated admins

DOCTOR SIGNUP FLOW:
-------------------
1. Doctor fills signup form with:
   - Personal info (name, email, phone)
   - Professional info (specialty, license number, experience)
   - Clinic location
   - Verification document upload (PDF/JPG/PNG, max 5MB)

2. Account created with:
   - verificationStatus: PENDING
   - isActive: false
   - Document stored in /uploads/verification-documents/

3. Doctor cannot login until approved

ADMIN APPROVAL FLOW:
--------------------
1. Admin navigates to Doctors page
2. Filters by PENDING status
3. Reviews doctor details and clicks "View Document"
4. Document opens in modal for review
5. Admin clicks "Approve" or "Reject"
6. For approval:
   - verificationStatus → APPROVED
   - isActive → true
   - verifiedAt → current timestamp
   - verifiedBy → admin ID
7. For rejection:
   - Admin must provide rejection notes
   - verificationStatus → REJECTED
   - isActive → false
   - verificationNotes → admin's notes
   - verifiedAt → current timestamp
   - verifiedBy → admin ID
