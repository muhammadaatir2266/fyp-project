📋 CALLING AGENT API ENDPOINTS
===========================================

All endpoints require API token authentication:
Authorization: Bearer <token>

1. GET /api/v1/doctors
   - Get list of all active doctors
   - Optional filter: ?specialty=Cardiology
   
2. GET /api/v1/doctors/:id/availability
   - Check if doctor is available at specific time
   - Required params: ?date=2024-03-15&time=14:30
   
3. GET /api/v1/doctors/:id/slots
   - Get all available time slots for a day
   - Required param: ?date=2024-03-15
   
4. POST /api/v1/doctors/:id/appointments
   - Book an appointment
   - Body: { patientName, patientPhone, patientEmail, date, time, reason }

All API calls are automatically logged in the database.
