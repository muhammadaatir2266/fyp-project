IMPORTANT NOTE:
---------------
Whenever you update the Prisma schema, you MUST run `npx prisma generate` to regenerate the Prisma client. Otherwise, the TypeScript types and runtime client won't include the new fields.

For production deployment:
- Run migrations: npx prisma migrate deploy (from admin backend only)
- Generate clients: npx prisma generate (in each backend before deployment)
