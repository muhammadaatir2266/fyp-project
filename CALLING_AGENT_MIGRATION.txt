API ENDPOINT CHANGES
===========================================

OLD (fyp-doctor):
----------------
Base URL: http://localhost:5000/api/public
Authentication: None (Public endpoints)

Endpoints:
- GET  /api/public/doctors
- GET  /api/public/doctors/:id/availability
- GET  /api/public/doctors/:id/slots
- POST /api/public/doctors/:id/appointments

NEW (fyp-admin):
---------------
Base URL: http://localhost:4000/api/v1
Authentication: API Token Required (Bearer token)

Endpoints:
- GET  /api/v1/doctors
- GET  /api/v1/doctors/:id/availability
- GET  /api/v1/doctors/:id/slots
- POST /api/v1/doctors/:id/appointments

MIGRATION STEPS FOR EXTERNAL SYSTEMS
===========================================

If you have external systems using the old API:

1. Generate API Token:
   - Login to admin panel (http://localhost:3002)
   - Navigate to "API Access"
   - Click "Generate Token"
   - Copy the token

2. Update Base URL:
   OLD: http://localhost:5000/api/public
   NEW: http://localhost:4000/api/v1

3. Add Authentication Header:
   Authorization: Bearer YOUR_API_TOKEN

4. Test Endpoints:
   - Use the API Docs page for examples
   - All endpoints work the same way
   - Only authentication is added

EXAMPLE MIGRATION
===========================================

OLD Request (No Auth):
---------------------
curl -X GET "http://localhost:5000/api/public/doctors"

NEW Request (With Token):
------------------------
curl -X GET "http://localhost:4000/api/v1/doctors" \
  -H "Authorization: Bearer YOUR_API_TOKEN"

TESTING THE MIGRATION
===========================================

1. Start fyp-admin backend:
   cd fyp-admin/backend
   npm run dev
   (Should run on port 4000)

2. Generate API token:
   - Login to admin panel
   - Go to API Access
   - Generate token

3. Test endpoints:
   curl -X GET "http://localhost:4000/api/v1/doctors" \
     -H "Authorization: Bearer YOUR_TOKEN"

4. Check logs:
   - Go to API Logs in admin panel
   - Verify your call is logged

TROUBLESHOOTING
===========================================

Issue: "API token required"
Solution: Add Authorization header with Bearer token

Issue: "Invalid API token"
Solution: Generate new token from admin panel

Issue: "API token has been revoked"
Solution: Token was revoked, generate new one

Issue: "API token has expired"
Solution: Generate new token or use one without expiration

Issue: Old endpoints not working
Solution: Update to new base URL (port 4000, /api/v1)
