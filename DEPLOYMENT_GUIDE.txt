===========================================
DEPLOYMENT GUIDE - Quick Reference
===========================================

STRATEGY
===========================================

Development:  Single prisma/ in root → All backends reference ../../prisma/
Production:   Copy prisma/ to each backend → All connect to SAME database

PRE-DEPLOYMENT
===========================================

Run this script to prepare:
```powershell
.\prepare-deployment.ps1
```

Or manually:
```bash
cp -r prisma fyp-admin/backend/
cp -r prisma fyp-doctor/backend/
cp -r prisma fyp-patient/backend/
```

DEPLOYMENT STEPS
===========================================

1. Create Production Database:
   CREATE DATABASE fyp_healthcare_prod;

2. Deploy Admin Backend (FIRST):
   - Set DATABASE_URL to production
   - npm install
   - npx prisma generate
   - npx prisma migrate deploy  ← Run migrations ONCE
   - npm start

3. Deploy Doctor Backend:
   - Set SAME DATABASE_URL
   - npm install
   - npx prisma generate  ← NO migrations
   - npm start

4. Deploy Patient Backend:
   - Set SAME DATABASE_URL
   - npm install
   - npx prisma generate  ← NO migrations
   - npm start

ENVIRONMENT VARIABLES
===========================================

All backends need SAME DATABASE_URL:
```
DATABASE_URL="postgresql://user:pass@host:5432/fyp_healthcare_prod"
JWT_SECRET="unique-secret-per-backend"
NODE_ENV="production"
FRONTEND_URL="https://your-domain.com"
```

IMPORTANT RULES
===========================================

✅ Copy prisma/ to each backend before deployment
✅ Use SAME DATABASE_URL for all backends
✅ Run migrations ONLY from admin backend
✅ Generate Prisma Client in each backend

❌ Don't run migrations from multiple backends
❌ Don't use different databases

SCHEMA UPDATES
===========================================

1. Update prisma/schema.prisma locally
2. Run prepare-deployment.ps1
3. Deploy admin → npx prisma migrate deploy
4. Deploy others → npx prisma generate only

TROUBLESHOOTING
===========================================

"Prisma Client not found" → npx prisma generate
"Migration failed" → Check DATABASE_URL
"Connection timeout" → Check firewall/host access
