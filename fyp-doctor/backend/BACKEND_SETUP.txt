DOCTOR DASHBOARD BACKEND - SETUP INSTRUCTIONS
==============================================

PREREQUISITES:
- Node.js (v18 or higher)
- PostgreSQL database running
- npm or yarn package manager

SETUP STEPS:

1. Install Dependencies:
   cd backend
   npm install

2. Configure Environment:
   - Copy .env.example to .env
   - Update DATABASE_URL with your PostgreSQL credentials:
     DATABASE_URL="postgresql://username:password@localhost:5432/medical_assistant?schema=public"
   - Update JWT_SECRET (keep it secure!)
   - Update FRONTEND_URL if needed (default: http://localhost:3001)

3. Setup Database:
   # Generate Prisma Client
   npx prisma generate

   # Run migrations to create tables
   npx prisma migrate dev --name init

   # Seed the database with sample data
   npx prisma db seed

4. Start the Server:
   npm run dev
   
   The API will run on http://localhost:5000

5. Test the API:
   Visit: http://localhost:5000/api/health
   Should return: {"status":"OK","message":"Doctor Dashboard API is running"}

TROUBLESHOOTING:
================

1. Database Connection Error:
   - Verify PostgreSQL is running
   - Check DATABASE_URL in .env
   - Ensure database exists

2. Prisma Client Error:
   - Run: npx prisma generate
   - Restart the server

3. Port Already in Use:
   - Change PORT in .env file
   - Update NEXT_PUBLIC_API_URL in frontend .env.local

4. JWT Token Error:
   - Ensure JWT_SECRET is set in .env
   - Check token expiration settings

DEVELOPMENT COMMANDS:
=====================
npm run dev      - Start development server with nodemon
npm start        - Start production server
npx prisma studio - Open Prisma Studio (database GUI)
npx prisma migrate dev - Create new migration
npx prisma db seed - Reseed database

PRODUCTION DEPLOYMENT:
======================
1. Set NODE_ENV=production in .env
2. Update DATABASE_URL to production database
3. Run migrations: npx prisma migrate deploy
4. Start server: npm start

SECURITY NOTES:
===============
- Change JWT_SECRET in production
- Use strong passwords
- Enable HTTPS in production
- Set proper CORS origins
- Keep dependencies updated
