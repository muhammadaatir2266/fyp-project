===========================================
QUICK SETUP COMMANDS
===========================================

# Backend
cd fyp-doctor/backend
echo 'DATABASE_URL="postgresql://postgres:password@localhost:5432/doctor_dashboard"' > .env
echo 'JWT_SECRET="your-secret-key-here"' >> .env
echo 'PORT=5000' >> .env
echo 'NODE_ENV=development' >> .env
echo 'FRONTEND_URL=http://localhost:3001' >> .env

# Frontend
cd fyp-doctor/frontend
echo 'NEXT_PUBLIC_API_URL=http://localhost:5000/api' > .env.local

===========================================
IMPORTANT NOTES
===========================================

1. NEVER commit .env files to Git (they're in .gitignore)
2. Change JWT_SECRET to a random string in production
3. Update DATABASE_URL with your actual PostgreSQL credentials
4. Make sure PostgreSQL is running before starting backend
5. Frontend uses NEXT_PUBLIC_ prefix for client-side variables
