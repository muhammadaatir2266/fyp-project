🚀 QUICK START COMMANDS
========================

Backend (Terminal 1):
---------------------
cd fyp-doctor/backend
npm install
npx prisma generate
npx prisma migrate dev --name init
npx prisma db seed
npm run dev

Frontend (Terminal 2):
----------------------
cd fyp-doctor/frontend
npm install
npm run dev

Access:
-------
Frontend: http://localhost:3001
Backend:  http://localhost:5000
Login:    doctor@example.com / doctor123
